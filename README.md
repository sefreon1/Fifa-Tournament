# Fifa Tournering

En enkel turneringsapp för FIFA/EA FC (och andra spel) på PS5. Allt ligger i en enda `index.html` – ingen installation, ingen server.

## Funktioner
- Välj antal lag (2–16), spelare per lag och matcher per lag
- Namnge lag och spelare
- Slumpat schema där alla lag spelar lika många matcher
- Välj själv vilka lag som möts i match 1, 2, 3 … och slumpa resten
- Resultat sparas automatiskt i webbläsaren
- Tabell och turneringsfakta
- Slutspel: utslagscup, Page-slutspel eller direktfinal (bäst av 1/3/5, bronsmatch, straffar)
- Statistik per lag: form, sviter, poängutveckling, mål per match
- Backup/återställ via text

## Använda
Öppna `index.html` i en webbläsare, eller aktivera GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

Data sparas lokalt i webbläsaren på respektive enhet.
